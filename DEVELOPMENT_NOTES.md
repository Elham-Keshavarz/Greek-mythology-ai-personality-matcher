# Development notes

This project was developed iteratively, but the public repository uses **one unversioned project identity**.
This file records capability changes, rather than assigning numbered project releases.

## GitHub preparation

- Added GitHub Actions offline CI, a privacy-aware publication checklist, security scanning and documentation.
- Added a recorded retrieval evaluation snapshot with appropriate corpus-derived benchmark limitations.
- Added an optional manual faithfulness review workflow, without claiming unmeasured model accuracy.

## Personalized mythology explanations

- Added deterministic Big Five trait-gap explanations with optional, consent-based OpenAI commentary.
- Improved evidence validation for Athena's owl and olive-tree symbols.

## Grounded LLM responses

- Required a single approved excerpt before optional generation, with citation-ID validation and safe abstention.
- Added offline generation tests and opt-in live evaluation.

## Foundational retrieval and quiz

- Built the 50-item questionnaire, 45 manually authored profiles, persistent pagination and optional candidate-gender filtering.
- Added local embeddings and FAISS, typo normalization, hybrid reranking and passage-level evidence checks.

This is a portfolio/educational demonstration, not a validated psychometric or fact-verification product.
